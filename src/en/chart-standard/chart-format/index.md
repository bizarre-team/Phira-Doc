# Chart File Formats

Supported chart formats:

- RPE format: see [RPE docs](./rpe/root.md)
- PEC format: see [PE docs](./pe/index.md)
- PBC format (docs TBD)

The format is inferred from the `format` field in `info.yml`. If that field is empty, it is inferred from the file contents.

::: warning Note
The chart file extension is ignored.
:::
