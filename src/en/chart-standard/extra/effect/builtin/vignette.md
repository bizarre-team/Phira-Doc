# `vignette`

Vignette effect. Darkens the edges of the screen or tints them with another color. It can be used to imitate some Arcaea anomaly effects.

![Example](image/vignette.png)

## Parameters

- `color` (color, default black `[r, g, b, a]`): Color of the screen edges.
- `extend` (float, default `0.25`, range 0–1): How far the darkened edge extends. Larger values make the darkened area larger.
- `radius` (float, default `15.0`): Size of the bright area in the center. Smaller values make the affected area larger.
