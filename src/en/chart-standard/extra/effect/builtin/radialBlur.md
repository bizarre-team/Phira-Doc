# `radialBlur`

Radial blur effect.

![Example](image/radialBlur.png)

## Parameters

- `centerX` (float, default `0.5`, range 0–1): X coordinate of the blur center.
- `centerY` (float, default `0.5`, range 0–1): Y coordinate of the blur center.
- `power` (float, default `0.01`, range 0–1): Strength of the radial blur.
- `sampleCount` (int, default `3`, range 1–64): Number of samples. Higher values produce smoother results, but cost more performance.
