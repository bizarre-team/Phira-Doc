# `shockwave`

Shockwave effect. It is best used together with animation on `progress`.

![Example](image/shockwave.png)

## Parameters

- `progress` (float, default `0.2`, range 0–1): Progress of the shockwave animation. `0` is the beginning and `1` is the end.
- `centerX` (float, default `0.5`, range 0–1): X coordinate of the shockwave center.
- `centerY` (float, default `0.5`, range 0–1): Y coordinate of the shockwave center.
- `width` (float, default `0.1`): Width of the shockwave.
- `distortion` (float, default `0.8`): Amount of distortion.
- `expand` (float, default `10.0`): How far the shockwave spreads.
